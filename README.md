# IZO — Desafío turnos (entregas)

Repo de **entregas** del desafío final del workshop *Fundamentos de IA para Desarrolladores*.

Material del taller (slides, demos): repo separado. Acá solo consignas, rúbrica y PRs de alumnos.

| Documento | Para qué |
|-----------|----------|
| [CONSIGNA.md](./CONSIGNA.md) | Spec dada + entregables |
| [RUBRICA.md](./RUBRICA.md) | Criterios y puntajes (100) |
| [FLUJO-ENTREGA.md](./FLUJO-ENTREGA.md) | Cómo abrir el PR (sin fork) |
| [evaluacion/CHECKLIST.md](./evaluacion/CHECKLIST.md) | Checklist alumno / docente |
| [evaluacion/PROMPT-EVALUADOR.md](./evaluacion/PROMPT-EVALUADOR.md) | Instrucciones del agente evaluador |
| [plantillas/](./plantillas/) | `SPEC.md` y `AI.md` de partida |

## Alumnos

1. Leé `CONSIGNA.md` y `FLUJO-ENTREGA.md`.
2. Branch `entrega/<tu-usuario-github>`.
3. Proyecto en `entregas/<tu-usuario-github>/`.
4. PR a `main` → devolución automática en el PR.

## Docentes

1. Agregar alumnos como collaborators (mismo repo; **no forks**).
2. Activar la Automation de Cursor (evaluador) sobre este repo.
3. Revisar comentarios del agente; ajustar nota final con la rúbrica.
