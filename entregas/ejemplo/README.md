# Entrega de ejemplo — desafío turnos

Entrega **de prueba** para validar la Automation del evaluador. No es una solución completa a propósito.

## Auth

Header `X-User-Id`.

## Cómo correr

```bash
cd entregas/ejemplo
npm install
npm test
```

No hay servidor HTTP en esta entrega de ejemplo: la lógica vive en `src/appointments.js` y se prueba con Vitest.

```bash
npm test
```
